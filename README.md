# 🎉 CaroCorp - Gestion Location Vaisselle Événements

**Version** : 0.1.0  
**Statut** : 🚧 En développement  
**Architecture** : Option C (Multi-Repo) - Indépendant de MassaCorp

---

## 📋 Description

CaroCorp est une API de gestion de location de vaisselle et accessoires pour événements.

**Fonctionnalités** :
- 📦 Gestion catalogue articles (assiettes, verres, couverts, nappes, etc.)
- 📅 Réservations événements
- 📊 Gestion stock et disponibilité
- 💰 Facturation et paiements
- 👥 Gestion clients

## 🚀 Quick Start

```bash
# Démarrer les services
docker compose up -d

# Accéder à l'API
http://localhost:8001/docs
```
