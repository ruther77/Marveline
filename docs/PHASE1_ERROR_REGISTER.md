## Decision rules
1. Toute issue `S0` doit avoir un ticket d'implémentation + test E2E avant nouveau scope fonctionnel.
2. Toute issue `S1` doit être planifiée dans le train suivant, pas en backlog infini.
3. Une issue ne passe en `Closed` que si DoD usage complet est satisfait.
